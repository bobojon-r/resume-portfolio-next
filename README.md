# Портфолио-резюме (Next.js + Tailwind)

Готово к деплою на Vercel.

## Локальный запуск
```bash
npm i
npm run dev
```

## Деплой на Vercel
1. Создай новый репозиторий на GitHub и залей сюда файлы.
2. В Vercel -> Add New Project -> Import из GitHub -> Framework: **Next.js** -> Deploy.
3. Перед публикацией замените `public/avatar.svg` своей фотографией.

## Настройка контента
Редактируйте `lib/data.ts`: имя, позицию, опыт, образование, навыки, проекты и контакты.
Пустые ссылки на проекты не будут показаны на сайте.
Замените `public/avatar.svg` своей фотографией (например, `avatar.jpg`) и измените путь в `app/page.tsx`.
